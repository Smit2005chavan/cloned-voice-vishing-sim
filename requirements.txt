# ── Mac setup notes (ai_voice_demo_local.py) ──────────────────────────
# - Recommend a Python 3.11 venv for this script specifically -- F5-TTS's
#   dependency chain (transformers, x_transformers, torchdiffeq, vocos,
#   hydra-core) is far more proven on 3.11 than on very new Python versions.
# - brew install ffmpeg -- model.infer(..., remove_silence=True) uses
#   pydub, which shells out to ffmpeg on $PATH. If that's a blocker, set
#   remove_silence=False in ai_voice_demo_local.py's _synthesize_sentence_sync
#   (small quality trade-off, not a functional blocker).
# - xcode-select --install -- cheap insurance in case any transitive
#   dependency needs to build from source.
# - f5-tts pulls a large dependency tree (gradio, transformers, accelerate,
#   torchcodec, etc.) -- expect a slow, multi-GB install, plus a multi-GB
#   model-weight download from Hugging Face on first run.
# - macOS 12.3+ required for the "mps" GPU backend.
